Overview

The website works. The iOS connection is paused.

The PHP and MySQL website handles motorcycle listings and test ride bookings, with inventory and bookings stored in a SQL database. Customers choose a motorcycle, pick a date and time, enter their details, then review the booking.

The iOS prototype works against the local PHP API and SQL database. Connecting it to the live site is paused.

Test ride bookings

The server checks availability before saving a booking.

The booking form has four steps: choose a motorcycle, pick a date and time, enter customer details, then confirm. Availability is checked against existing bookings, and the submitted booking is validated again on the server.

That second check matters. A time slot might be taken after someone starts filling in the form.

Web & iOS

The iOS prototype works locally, but not against the hosted site yet.

The app uses the local PHP API and SQL database. Requests from the prototype to the hosted domain are blocked as bot traffic, so the full iOS-to-hosted-site setup isn’t working yet.
