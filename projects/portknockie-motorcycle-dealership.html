01

Overview

This project takes the motorcycle software into a dealership environment.

The current focus is a practical dealership workflow where motorcycles can be managed and customers can move through a clear test ride booking process.

The booking journey is split into deliberate steps so availability, customer details and booking information can be validated at the right point in the flow.

02

Booking journey

The booking flow is designed around preventing invalid bookings before they reach the database.

The four-step journey separates motorcycle selection, date and time selection, customer information and confirmation. Availability is checked against existing bookings and the final submission is validated again before the booking is created.

This makes the workflow easier to understand for users while keeping the important validation on the server.

03

Engineering

The project is being developed as a real continuation rather than a one-off university prototype.

The database includes motorcycle inventory and booking data, with the application logic responsible for availability and validation. The interface is intentionally kept clean so the booking process is the focus.

Recent work has concentrated on refining the booking UI, handling booking-time validation and making the journey behave reliably from start to finish.

04

Next steps

The dealership system is still being developed.

Further work will expand the dealership functionality while keeping the same emphasis on reliable workflows, database integrity and a polished user experience.
