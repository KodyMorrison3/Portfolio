Motorcycle Dealership.

A dealership management system focused on motorcycle inventory, availability and a polished multi-step test ride booking journey, with a development iOS app being built alongside the web application.

PHPMySQLJavaScriptCSSSwiftiOS
In active development
01

Overview

This project takes the motorcycle software into a dealership environment and now covers both web and iOS development.

The current focus is a practical dealership workflow where motorcycles can be managed and customers can move through a clear test ride booking process.

The web application is being developed alongside a native iOS app, giving me the opportunity to work on the same project across both web and mobile platforms.

02

Booking journey

The booking flow is designed around preventing invalid bookings before they reach the database.

The four-step journey separates motorcycle selection, date and time selection, customer information and confirmation. Availability is checked against existing bookings and the final submission is validated again before the booking is created.

This makes the workflow easier to understand for users while keeping the important validation on the server.

03

Web & iOS

The project is now being developed across two platforms.

The dealership website handles the main customer and administration workflows, while a native iOS app is being developed alongside it using Swift and Xcode.

The iOS app is still in development, but it gives the project a second platform and lets me explore native mobile development alongside the PHP and MySQL web application.

04

Engineering

The project is being developed as a real continuation rather than a one-off university prototype.

The database includes motorcycle inventory and booking data, with the application logic responsible for availability and validation. The interface is intentionally kept clean so the booking process is the focus.

Recent work has concentrated on refining the booking UI, handling booking-time validation and making the journey behave reliably from start to finish.

05

Next steps

The dealership system and iOS app are still being developed.

Further work will expand the dealership functionality and continue development of the iOS app while keeping the same emphasis on reliable workflows, database integrity and a polished user experience.
