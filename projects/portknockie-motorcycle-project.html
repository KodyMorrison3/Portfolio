Portknockie
Motorcycle Project.

A complete server-rendered web application combining motorcycle servicing, customer accounts, bookings, e-commerce and administration.

PHPMySQLJavaScriptCSSSecurity
Completed project

Overview

I built this as a complete motorcycle business platform, not a collection of separate pages.

It covers customer registration and authentication, servicing bookings, an online store with basket and checkout, administration and contact management.

It’s a server-rendered PHP and MySQL application, with JavaScript and CSS handling client-side interaction where it helps.

Engineering

The interesting part was connecting the individual features into one consistent system.

I designed the database around the relationships between users, motorcycles, bookings, services, products, orders and administration data.

Authentication, sessions, role-based access control, validation and database queries were built into the application rather than treated as separate extras.

Security

Security was considered throughout the application.

  • Bcrypt password hashing
  • Session handling and regeneration
  • Role-based access control
  • CSRF protection
  • Input validation and sanitisation
  • SQL injection prevention
  • XSS prevention

Testing

Over 200 documented manual tests, with failures fixed before submission.

I wrote manual test documentation covering the application’s main workflows and edge cases. The final round covered more than 200 individual tests, and I investigated and corrected failures before submission.

What I learned

Building the whole system made the connections between frontend, backend, database and security much clearer.

The project strengthened my understanding of application structure, relational database design, authentication and testing. It also gave me the foundation for the dealership project that followed.
